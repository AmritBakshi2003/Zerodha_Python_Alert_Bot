        What this tool is, and what to do on your first day.

        Version
        …
        Mode
        …

        This tool only sends alerts. It never places, modifies or cancels orders.

        Your first day

        1. Copy .env.example to .env and fill in your Kite keys.
        2. Run kite-alerts config-check to confirm the settings are valid.
        3. Run kite-alerts login each morning — the token expires around 06:00 IST.
        4. Run kite-alerts run in its own window to start the alerts.
        5. Try the demo player on this page first: it needs no account and no internet.

        This dashboard is served entirely from this computer. No CDN, no external fonts, no analytics and no telemetry.
