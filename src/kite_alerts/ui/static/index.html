      Guided notifications

      Alerts are useful only if they reach you. The terminal window is always on; these add a phone or a team channel.

      Telegram

      1. Open @BotFather in Telegram and create a bot. Copy the token it gives you.
      2. Paste the token in “Telegram bot token” above, choose Telegram under Channels, and save.
      3. Open your new bot and press Start, then press “Find my chat id” here.

      The chat id fills in above; save again to keep it.

      Slack

      1. In Slack, create an Incoming Webhook for the channel you want.
      2. Paste the webhook URL in “Slack webhook URL” above, choose Slack under Channels, and save.

      The URL is stored write-only and never shown again.

      Send a test

      Sends one clearly labelled TEST message through every configured channel. It is never recorded as a real alert, and you can send one every 10 seconds.

            This tool only sends alerts. It never places, modifies or cancels orders.

            Your first day

            1. Open Connect and create your own Kite Connect app.
            2. Paste the key and secret, then log in on Zerodha's page.
            3. Choose instruments and a notification channel on Settings.
            4. Run kite-alerts run in its own window to start the alerts.

            If something goes wrong

            • “Redirect URL mismatch” on Zerodha. The URL in your Kite app must match the address shown on Connect exactly, including the port. Copy it again from step 2.
            • “Token expired”. Kite tokens last until about 06:00 IST. Press Connect again; the bot itself needs a fresh token each morning too.
            • “Your Kite plan has no market data”. Login succeeded but your plan does not include live quotes. The dashboard will use delayed data instead.
            • “Port in use”. Something else is on 8765. Start the dashboard with kite-alerts ui --port 8766 and put the new redirect URL into your Kite app.
